# Крийя Йога - Приложение для изучения

Веб-приложение для изучения курса "Древние тантрические техники йоги и крийи. Том I. Вводный курс".

## Функции

### 📚 Список уроков
- 12 уроков с темами
- Навигация по содержанию в боковой панели
- Переход между страницами внутри тем

### 📖 Страницы для чтения
-Formatted текст с сохранением структуры оригинала
- Нумерация страниц
- Навигация вперед/назад

### 🔍 Поиск
- Полнотекстовый поиск по всем материалам
- Отображение результатов с контекстом
- Быстрый переход к найденному

### 🔖 Закладки
- Сохранение конкретных страниц
- Быстрый доступ через меню закладок
- Управление (добавление/удаление)

### ❤️ Избранное
- Отметка целых тем как избранных
- Быстрый доступ к любимым материалам

### 📊 Отслеживание прогресса
- Процент пройденного материала
- Прогресс по каждому уроку
- Автоматическое сохранение

## Установка и запуск

1. Откройте папку `yoga-app` в вашем файловом менеджере
2. Дважды кликните на `index.html` для открытия в браузере

Или используйте локальный сервер:

```bash
# Python 3
cd yoga-app
python3 -m http.server 8000

# Затем откройте http://localhost:8000 в браузере
```

## Структура файлов

```
yoga-app/
├── index.html      # Главный HTML файл
├── styles.css      # Стили приложения
├── app.js          # Логика приложения
├── README.md       # Этот файл
└── data/
    └── book.json   # Данные книги (уроки, темы, страницы)
```

## Технические детали

- **Чистый JavaScript** - без внешних зависимостей
- **LocalStorage** - сохранение данных пользователя (закладки, избранное, прогресс)
- **Адаптивный дизайн** - работает на компьютерах, планшетах и телефонах
- **Оффлайн работа** - после загрузки не требует интернета

## Данные

Приложение использует данные из файла `data/book.json`, который содержит:
- Название книги
- 12 уроков с темами
- 72 раздела контента
- 357 страниц текста

Все данные автоматически генерируются из исходного файла `data` репозитория.

## Совместимость

- Современные браузеры (Chrome, Firefox, Safari, Edge)
- Мобильные браузеры (iOS Safari, Chrome Android)
- Требуется поддержка ES6+ и localStorage
